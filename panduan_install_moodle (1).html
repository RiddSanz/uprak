4Secure MySQL Installation

Jawaban untuk pertanyaan:

1. VALIDATE PASSWORD COMPONENT:
→ Ketik: n (No) - tidak perlu password complexity

2. Set root password:
→ Ketik: y (Yes)
→ Password: RootDB123! (atau password Anda)
→ Re-enter password: RootDB123!

3. Remove anonymous users:
→ Ketik: y (Yes)

4. Disallow root login remotely:
→ Ketik: n (No) - kita butuh akses remote

5. Remove test database:
→ Ketik: y (Yes)

6. Reload privilege tables:
→ Ketik: y (Yes)

5Buat Database dan User untuk Moodle

# Login ke MySQL sebagai root
sudo mysql -u root -p
# Masukkan password root: RootDB123!
📝 Setelah masuk ke MySQL prompt, jalankan SQL berikut: 
-- Buat database moodle
CREATE DATABASE moodle DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- Buat user moodleuser dengan akses dari manapun (%)
CREATE USER 'moodleuser'@'%' IDENTIFIED BY 'Moodle123!';

-- Berikan semua privilege pada database moodle
GRANT ALL PRIVILEGES ON moodle.* TO 'moodleuser'@'%';

-- Flush privileges
FLUSH PRIVILEGES;

-- Cek database yang sudah dibuat
SHOW DATABASES;

-- Keluar dari MySQL
EXIT;
✅ Database moodle dan user moodleuser berhasil dibuat!

6Konfigurasi MySQL untuk Remote Access

# Edit konfigurasi MySQL
sudo nano /etc/mysql/mysql.conf.d/mysqld.cnf
Cari baris yang berisi: 
bind-address = 127.0.0.1
Ubah menjadi: 
bind-address = 0.0.0.0
Atau tambahkan baris ini jika tidak ada: 
bind-address = 0.0.0.0
mysqlx-bind-address = 0.0.0.0
💡 Cara edit di nano:
• Gunakan arrow keys untuk navigasi
• Edit teks sesuai kebutuhan
• Tekan Ctrl + O untuk save
• Tekan Enter untuk konfirmasi
• Tekan Ctrl + X untuk keluar 
# Restart MySQL
sudo systemctl restart mysql

# Cek status
sudo systemctl status mysql

14Copy Moodle ke Web Directory

# Copy dari /opt/moodle ke /var/www/html/
sudo cp -R /opt/moodle /var/www/html/

# Buat direktori moodledata untuk file uploads
sudo mkdir /var/moodledata

# Set ownership ke www-data (user Apache)
sudo chown -R www-data:www-data /var/www/html/moodle
sudo chown -R www-data:www-data /var/moodledata

# Set permissions
sudo chmod -R 755 /var/www/html/moodle
sudo chmod -R 777 /var/moodledata
⚠️ Penjelasan Permission:
• 755 = Owner bisa read/write/execute, others read/execute
• 777 = Semua user bisa read/write/execute (untuk uploads)

15Konfigurasi Apache Virtual Host

# Buat file konfigurasi Moodle
sudo nano /etc/apache2/sites-available/moodle.conf
Copy-paste konfigurasi berikut: 
<VirtualHost *:80>
    ServerAdmin admin@localhost
    DocumentRoot /var/www/html/moodle
    
    <Directory /var/www/html/moodle>
        Options FollowSymlinks
        AllowOverride All
        Require all granted
    </Directory>
    
    ErrorLog ${APACHE_LOG_DIR}/moodle_error.log
    CustomLog ${APACHE_LOG_DIR}/moodle_access.log combined
</VirtualHost>
💡 Cara save di nano: Ctrl + O → Enter → Ctrl + X 
# Enable site Moodle
sudo a2ensite moodle.conf

# Disable default site
sudo a2dissite 000-default.conf

# Enable rewrite module
sudo a2enmod rewrite

# Test konfigurasi Apache
sudo apache2ctl configtest

# Restart Apache
sudo systemctl restart apache2
✅ Jika muncul "Syntax OK", konfigurasi Apache benar!

💾 BAGIAN 6: BACKUP & RESTORE (UNTUK UJIAN)

33Setup Automatic Backup - Database

Di VM Database Server (192.168.xx.3): 
# Buat direktori backup
sudo mkdir -p /backup

# Buat script backup
sudo nano /usr/local/bin/backup-db.sh
Copy script berikut: 
#!/bin/bash
# Script backup database Moodle

DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="/backup"
DB_NAME="moodle"
DB_USER="root"
DB_PASS="RootDB123!"

# Buat direktori backup jika belum ada
mkdir -p $BACKUP_DIR

# Backup database
mysqldump -u $DB_USER -p$DB_PASS $DB_NAME > $BACKUP_DIR/moodle_db_$DATE.sql

# Compress backup
tar -czf $BACKUP_DIR/moodle_db_$DATE.tar.gz $BACKUP_DIR/moodle_db_$DATE.sql

# Hapus file SQL yang belum dikompress
rm $BACKUP_DIR/moodle_db_$DATE.sql

# Hapus backup lebih dari 7 hari
find $BACKUP_DIR -name "moodle_db_*.tar.gz" -mtime +7 -delete

echo "Database backup completed: $BACKUP_DIR/moodle_db_$DATE.tar.gz"
# Set executable permission
sudo chmod +x /usr/local/bin/backup-db.sh

# Test script
sudo /usr/local/bin/backup-db.sh

# Cek hasil backup
ls -lh /backup/

34Setup Automatic Backup - Web Files

Di VM Web Server (192.168.xx.2): 
# Buat direktori backup
sudo mkdir -p /backup

# Buat script backup
sudo nano /usr/local/bin/backup-web.sh
#!/bin/bash
# Script backup Moodle files

DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="/backup"

# Buat direktori backup jika belum ada
mkdir -p $BACKUP_DIR

# Backup Moodle files dan config
tar -czf $BACKUP_DIR/moodle_files_$DATE.tar.gz \
    /var/www/html/moodle \
    /var/moodledata \
    /etc/apache2/sites-available/moodle.conf

# Hapus backup lebih dari 7 hari
find $BACKUP_DIR -name "moodle_files_*.tar.gz" -mtime +7 -delete

echo "Files backup completed: $BACKUP_DIR/moodle_files_$DATE.tar.gz"
# Set executable permission
sudo chmod +x /usr/local/bin/backup-web.sh

# Test script
sudo /usr/local/bin/backup-web.sh

# Cek hasil backup
ls -lh /backup/

35Setup Cronjob untuk Backup Otomatis

Di VM Database Server: 
# Edit crontab root
sudo crontab -e

# Pilih editor (pilih nano jika ditanya)
# Tambahkan baris berikut di akhir file:

# Backup database setiap hari jam 02:00
0 2 * * * /usr/local/bin/backup-db.sh >> /var/log/backup-db.log 2>&1
Di VM Web Server: 
# Edit crontab root
sudo crontab -e

# Tambahkan baris berikut:

# Backup files setiap hari jam 02:30
30 2 * * * /usr/local/bin/backup-web.sh >> /var/log/backup-web.log 2>&1
💡 Format Cronjob:
* * * * * command
┬ ┬ ┬ ┬ ┬
│ │ │ │ │
│ │ │ │ └─ Day of week (0-6, 0=Sunday)
│ │ │ └─── Month (1-12)
│ │ └───── Day of month (1-31)
│ └─────── Hour (0-23)
└───────── Minute (0-59) 
# Verifikasi cronjob
sudo crontab -l

🔧 TROUBLESHOOTING UMUM

❌ Error: "Cannot connect to database"

Solusi: 
# Cek MySQL running di DB server
sudo systemctl status mysql

# Cek bind-address
sudo nano /etc/mysql/mysql.conf.d/mysqld.cnf
# Pastikan: bind-address = 0.0.0.0

# Restart MySQL
sudo systemctl restart mysql

# Test koneksi dari web server
mysql -h 192.168.xx.3 -u moodleuser -p

# Cek firewall
sudo ufw status
sudo ufw disable  # untuk testing

❌ Error: "403 Forbidden"

Solusi: 
# Set permission
sudo chown -R www-data:www-data /var/www/html/moodle
sudo chmod -R 755 /var/www/html/moodle
sudo chmod -R 777 /var/moodledata

# Restart Apache
sudo systemctl restart apache2

❌ Error: "PHP extension not found"

Solusi: 
# Install extension yang missing
sudo apt install php-[nama-extension] -y

# Contoh:
sudo apt install php-mysql php-xml php-mbstring php-curl php-zip php-gd -y

# Restart Apache
sudo systemctl restart apache2

❌ Moodle sangat lambat

Solusi: 
# Install PHP OPcache
sudo apt install php-opcache -y

# Restart Apache
sudo systemctl restart apache2

# Login as admin → Site administration → Plugins → Caching → Configuration
